# Compilador de Lenguaje Logístico para Olva Courier

Proyecto de análisis léxico para las tramas codificadas de paquetes de Olva Courier. La aplicación lee cada trama, la separa en lexemas, los clasifica en tokens y muestra, para cada token, su expresión regular, su AFND, su AFD, su tabla de transiciones y su quíntupla, con una simulación paso a paso de cómo se recorre una cadena.
